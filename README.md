# odin-recipies

This project is a the final project task from the HTML section in The Odin's Project.

Inside there are four recipes:
1. Egg Benedict
2. Smashed Burger
3. Bikini Sandwich
4. Lasagna (seems like TOP's personal favourite ^.^)

Completing this project has allowed me to remember the basic skills required in coding and the ability to research shortcuts in vs code, coding faster and easier and even learning more about the settings and ways to manipulate code.

Completing this project was fun, and hopefully, someday I'll try one of those amazing recipes!
